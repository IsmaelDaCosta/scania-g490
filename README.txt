Scania G490 - PWA offline

Cómo probarla en tu ordenador:
1. Descomprime esta carpeta.
2. Abre index.html en el navegador para ver la app.
3. Para que funcione el modo offline e instalarla en iPhone, súbela a un hosting HTTPS como GitHub Pages, Netlify o Vercel.

Cómo instalarla en iPhone:
1. Abre la dirección web en Safari.
2. Pulsa Compartir.
3. Pulsa Añadir a pantalla de inicio.
4. Abre la app desde el icono.

Datos:
- Se guardan en el propio iPhone usando almacenamiento local.
- No necesita cuenta, servidor ni internet después de instalarla.
